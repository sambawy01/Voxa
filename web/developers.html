Quick start

Make a key above, then send it as Authorization: Bearer vx_live_…. Keys act as your account and can be revoked at any time. Keep them out of public code.

Speak some text

curl -X POST __ORIGIN__/api/v1/speech \
  -H "Authorization: Bearer $VOXA_KEY" -H "Content-Type: application/json" \
  -d '{"text": "Hello from my agent.", "voice": "harper"}' -o hello.mp3

Make an audiobook

curl -X POST __ORIGIN__/api/v1/audiobooks \
  -H "Authorization: Bearer $VOXA_KEY" -H "Content-Type: application/json" \
  -d '{"title": "My Book", "text": "Chapter 1\n\nIt began on a quiet morning…"}'
# → {"id": "…", "status": "queued"}    then poll until "done":
curl -H "Authorization: Bearer $VOXA_KEY" __ORIGIN__/api/v1/jobs/JOB_ID
# → {"status": "done", "audio_url": "…/api/v1/files/….mp3", "chapters": [...]}

Make a podcast from a document

curl -X POST __ORIGIN__/api/v1/podcasts \
  -H "Authorization: Bearer $VOXA_KEY" -H "Content-Type: application/json" \
  -d '{"text": "…the article or report…", "minutes": 10, "tone": "friendly"}'

The finished job holds the written script and the MP3. Audio links need no key and expire after 24 hours.

Connect an AI agent (MCP)

Voxa is an MCP server, so Claude and other agents can use it as tools with no code. Add this to your agent's MCP settings:

{
  "mcpServers": {
    "voxa": {
      "type": "http",
      "url": "__ORIGIN__/mcp",
      "headers": { "Authorization": "Bearer vx_live_…" }
    }
  }
}

Tools: speak, make_audiobook, make_podcast, get_job, cancel_job, list_voices, get_account. Agents can also read /llms.txt or the OpenAPI description.

What it costs, and the limits

  • Studio voices only. The on-device voices run in a browser, so the API uses Studio voices. They draw on your plan: Voxa Lite has the one-time welcome credit and any HD packs; Voxa Studio has a monthly allowance.
  • Podcasts: Lite 1 a week up to 5 minutes; Studio 3 a day up to 20 minutes.
  • Audiobooks: Lite 1 new book a day; Studio unlimited. Up to about 7 hours of speech each.
  • Fair use: 2 audiobooks or podcasts being made at once, 120 requests a minute per key.
  • If a job fails, the characters it took are returned.
