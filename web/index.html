About the voices

Studio voices run Kokoro-82M (Apache 2.0) on our servers: one set of weights serves all nine languages, and repeated phrases come back instantly. On-device voices run Phonon 31m by Gradium (Apache 2.0) in your browser, so they cost nothing and work offline once loaded. Voice names are Voxa's own. Credits
