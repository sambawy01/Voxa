MCP & API

Voxa for AI assistants

Connect Voxa to Claude, ChatGPT or any AI. The AI writes the podcast or picks the text; Voxa's voices read it on your own device. Free, with no key and no limit: nothing is made on our servers.

  • MCP connectorFor apps that support MCP. The Voxa player appears in the chat, where the app can show it, or the AI gives you a link to it.
  • On your computerA local MCP server for desktop AI apps. Finished MP3s are saved in your Music folder.
  • REST APIFor anything else: custom GPTs, scripts, your own app. One call returns a player link.

In the Claude chat Free

  1. In Claude, open Settings → Connectors and choose Add custom connector.
  2. Name it Voxa and paste this address: 
    https://voxa-zpukmw.fly.dev/mcp
  3. In a new chat, turn on Voxa and ask: “Use Voxa to make a two-minute podcast about coffee, and play it.”

The player appears in the chat with a card for each speaker. The first time, your browser downloads the voices (tens of MB); after that they are kept. If the chat blocks the download, press Open in Voxa and save the MP3 there.

Claude Code and Claude Desktop, on your computer Free

  1. Install uv, a small tool that runs Voxa with everything it needs: 
    curl -LsSf https://astral.sh/uv/install.sh | sh
    powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
  2. Claude Code: run 
    claude mcp add voxa -- uv run https://voxa-zpukmw.fly.dev/voxa-mcp.py

    Claude Desktop: Settings → Developer → Edit Config, and put this in the file:

    {"mcpServers": {"voxa": {"command": "uv", "args": ["run", "https://voxa-zpukmw.fly.dev/voxa-mcp.py"]}}}

    On a Mac, if Claude Desktop cannot find uv, run which uv in Terminal and put that full path (usually /Users/you/.local/bin/uv) in place of "uv". Then restart Claude Desktop.

  3. Ask: “Use Voxa to read this article aloud in Lina’s voice.” The MP3 lands in Music → Voxa.

The first time, Voxa downloads its voices (111 MB) from this site; after that it works offline. Ten voices in 31 languages, including Arabic. To check it works: uv run https://voxa-zpukmw.fly.dev/voxa-mcp.py --check

A custom GPT Free

  1. In ChatGPT, open GPTs → Create, then Configure → Create new action.
  2. Choose Import from URL and paste: 
    https://voxa-zpukmw.fly.dev/openapi.json
    Set Authentication to None, and the privacy policy to 
    https://voxa-zpukmw.fly.dev/privacy
  3. In the GPT's instructions, add: “Write podcast scripts as ‘Name: line’ turns, call playPodcast, and give me the player link.”

The GPT answers with a link to the Voxa player. Open it and press Play: the voices run in your browser.

As an MCP connector Free

  1. Where your ChatGPT plan offers custom MCP connectors (in Settings, often under Apps or Connectors, with developer mode on), add a new one.
  2. Use this address, with no authentication: 
    https://voxa-zpukmw.fly.dev/mcp
  3. Ask: “Use Voxa to play a short podcast about the news I pasted.”

The menus differ between ChatGPT plans and change often; if you cannot find them, the custom GPT above works everywhere GPTs do.

Any MCP app Free

Cursor, VS Code, Windsurf, Gemini CLI, LM Studio and most AI apps can add an MCP server. Use one of these:

Remote server (Streamable HTTP, no key)

https://voxa-zpukmw.fly.dev/mcp

Local server (runs on your computer, saves MP3s)

uv run https://voxa-zpukmw.fly.dev/voxa-mcp.py

Examples

Cursor (~/.cursor/mcp.json), and most apps with an mcpServers file:

{"mcpServers": {"voxa": {"url": "https://voxa-zpukmw.fly.dev/mcp"}}}

VS Code (.vscode/mcp.json):

{"servers": {"voxa": {"type": "http", "url": "https://voxa-zpukmw.fly.dev/mcp"}}}

Gemini CLI (~/.gemini/settings.json):

{"mcpServers": {"voxa": {"httpUrl": "https://voxa-zpukmw.fly.dev/mcp"}}}

Any app, the local server:

{"mcpServers": {"voxa": {"command": "uv", "args": ["run", "https://voxa-zpukmw.fly.dev/voxa-mcp.py"]}}}

Apps that show MCP Apps get the Voxa player in the chat; others get a link that opens it here.

REST API Free

No key. Send a script; get a link to the Voxa player, which makes the audio in the browser of whoever opens it.

curl https://voxa-zpukmw.fly.dev/v1/play -H 'Content-Type: application/json' -d '{
  "title": "Coffee Talk",
  "script": "Maya: Welcome to Coffee Talk!\nLeo: Thanks, Maya. Today: espresso.",
  "style": "expressive"
}'

Answer: {"player_url": "…/player#d=…", "speakers": [{"name": "Maya", "voice": "wren"}, …], "minutes": 0.1}. Give text instead of script to read with one voice. Choose voices with "voices": {"Maya": "wren"} from:

curl 'https://voxa-zpukmw.fly.dev/v1/device/voices?language=ar'

Short scripts travel inside the link itself (after #, so they never reach a server). Longer ones are kept here as text for 30 days and the link carries an id. Up to 60,000 characters.

Things to ask

  • Make a podcast with three hosts about this PDF, in an expressive style.
  • Turn my notes into a five-minute episode and play it here.
  • Read chapter one of this story aloud, with a calm British voice.
  • Make the same episode in Arabic, with a man and a woman hosting.

Voices are synthetic: when you share what you make, say it is AI.
