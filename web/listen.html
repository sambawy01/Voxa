Read with Voxa from anywhere

Set it up once, then send text to Voxa from any app

📱 iPhone & iPad: Share menu and Siri
  1. Open the Shortcuts app and tap + to make a new shortcut. Name it Read with Voxa.
  2. Tap ⓘ (or the name at the top) and turn on Show in Share Sheet.
  3. In the first block, set it to receive Text from the Share Sheet, and under If there's no input choose Get Clipboard.
  4. Add the action URL Encode (it uses the Shortcut Input).
  5. Add the action Text and type https://voxavocals.com/listen#t=, then insert the URL Encoded Text variable right after it.
  6. Add the action Open URLs. Done.
  • From any app: select text, tap Share, then Read with Voxa. Tap ▶ when Voxa opens.
  • Hands-free: copy the text, then say "Hey Siri, Read with Voxa". It reads what you copied.
🏠 Put Voxa Reader on your Home Screen
  1. Open this page in Safari, tap Share, then Add to Home Screen.
  2. Copy any text, open Voxa from your Home Screen, and tap Paste & listen.
💻 Mac: right-click any text
  1. Your iPhone shortcut syncs to the Mac through iCloud. In the Mac's Shortcuts app, open Read with Voxa, click ⓘ, and turn on Use as Quick Action and Services Menu.
  2. In any app, select text, right-click, and choose Services → Read with Voxa.
🖥️ Any computer browser: one-click bookmark

Drag this button to your bookmarks bar. Select text on any web page (an email in Gmail or Outlook, an article), then click the bookmark.

🔊 Read with Voxa
🤖 Android: the Share menu
  1. Open this page in Chrome, tap ⋮, then Install app (or Add to Home screen).
  2. Select text in any app, tap Share, and choose Voxa.

Driving? Set this up before you go, and use Siri so your eyes and hands stay on the road.

Studio voices send the text to Voxa to be spoken and use the daily allowance. On-device voices (English) read on this device for free. Links in the text are read as "link", and quoted replies in emails are skipped.
